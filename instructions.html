Function description

介绍插件核心功能以及用法

Main color

它能够智能识别右键图片中的核心配色方案，无论你偏好哪一种色彩，都能无缝应用于后续的各项功能操作中，轻松满足多样化的色彩需求

It can intelligently identify the core color scheme in the right-clicked picture. No matter which color you prefer, it can be seamlessly applied to subsequent various functional operations, easily meeting diverse color requirements.

双击配色圈即可复制颜色
You can copy the color by double - clicking the color - matching circle.

Color according to choice

基于你挑选的色彩，它将通过系统化的色彩理论体系，为你呈现一系列兼具美感与专业性的适配色彩组合，满足多样化的色彩搭配需求

Based on the color you have selected, it will, through a systematic color theory system, present you with a series of aesthetically pleasing and professional color combinations that are suitable for the chosen color, meeting diverse color matching needs.

双击配色方块即可复制颜色
You can copy the color by double - clicking the color - matching square.

Main Color Gradient Preview

它能够从核心配色方案中，随机抽取两组不同色彩组合，以多元视角生动展示丰富的色彩搭配效果

It is capable of randomly extracting two different color combinations from the core color scheme, vividly demonstrating a rich variety of color matching effects from multiple perspectives.

占时不支持复制渐变颜色
Currently, copying gradient colors is not supported.

Q：当鼠标右键时不出现插件

表明右键处，没有图片或者没有识别到图片元素

Q: The plugin doesn't appear when the right - click button of the mouse is pressed.

It indicates that there is no picture at the right - click position or that the picture element has not been recognized.

Q：在某些网站图片上右键没有出现插件

刷新网页后再尝试，若还是不行，请通过邮件反馈

Q: The plugin doesn't appear when you right-click on the pictures of some websites.

Try again after refreshing the web page. If it still doesn't work, please provide feedback via email.

Q：插件响应变慢是什么情况

网络原因或者图片太大导致的，等待片或者刷新网页即可

Q: What's the situation if the plugin responds slowly?

It is caused by network issues or the fact that the picture is too large. Just wait for a while or refresh the web page.
